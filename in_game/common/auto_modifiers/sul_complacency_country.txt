# Complacency rework — REPLACE of vanilla complacency_impact.
#
# Removed: potential_trigger (effects always scale now), global_monthly_prosperity = 0.01
# Changed: estate_enrichment 0.2 → 0.25, pop_join_rebel_threshold 0.1 → 0.2
#
# scales_with = complacency × 0.01, so magnitudes below read as
# "effect at full complacency (100)".
#
# Direction of effects:

#   decay, estate dysfunction, economic bloat, rebellion sensitivity).
