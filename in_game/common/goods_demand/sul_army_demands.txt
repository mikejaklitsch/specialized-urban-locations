# Regiment Goods Demands — Standardized per 1k men
#
# Design: costs represent equipment upkeep + provisions + soldier life goods.
# Scaled by max_strength (regiment size in thousands).
#
# Tier scaling: ~15% increase per template era.
# Heavy variants: ~25% over their light counterpart.
# Cavalry/artillery at ~1.85x infantry base, close to each other.
# No single good dominates (max ~2:1 ducat ratio for non-elephant units).
#
# Goods prices used for balancing:
#   weaponry=3, firearms=3, cannons=4, leather=3, tools=3, cloth=3,
#   horses=3, elephants=10, lumber=1.5, copper=3, tin=2,
#   provisions=2.4, beer=2, liquor=2.5, salt=4, paper=2, medicaments=1,
#   jewelry=5
