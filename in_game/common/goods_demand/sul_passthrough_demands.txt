# =============================================================================
# PASSTHROUGH STOCKPILE + OVERSUPPLY TEMPLATES
# =============================================================================
# Adapted from yosiu_market_stockpiles workshop mod.
#
# _stockpile (negative): applied in the HIGH branch to push price down when
#   stockpile is above 5% capacity. Applied in the LOW branch with inverted
#   scale to push price up when stockpile is below 4.9% and the good is
#   in use by the market.
#
# _oversupply (positive): paired with each sul_<good>_warehouse building to
#   cancel the warehouse's +0.03 production at the flow layer. Net stockpile
#   contribution from the warehouse is zero, but the supply reading is
#   inflated — which is what vanilla's trade routing engine consumes.
# =============================================================================
