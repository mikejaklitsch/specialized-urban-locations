# =============================================================================
# POP DEMANDS WITH GDP PER CAPITA SCALING
# =============================================================================
#
# This file REPLACEs vanilla pop_demands.txt to add GDP-based demand scaling.
# Each goods entry uses a category-specific GDP scale with elasticity dampening:
#   sul_gdp_scale_necessity  (elasticity 0.2 — food, fuel, cloth, beer)
#   sul_gdp_scale_common     (elasticity 0.5 — tools, furniture, weapons)
#   sul_gdp_scale_upper      (elasticity 0.8 — wine, books, colonial goods)
#   sul_gdp_scale_luxury     (elasticity 1.0 — jewelry, spices, precious goods)
#
# Requires:
# - sul_local_gdp variable set on each location (by sul_update_all_location_gdp)
# - sul_gdp_scale_* script values (in sul_gdp_scaling.txt)
#
# =============================================================================
