# =============================================================================
# POP DEMANDS WITH GDP PER CAPITA SCALING + MARKET PRICE ADJUSTMENT
# =============================================================================
#
# This file REPLACEs vanilla pop_demands.txt to add GDP-based demand scaling
# with live market price correction. Each good's demand is adjusted by
# (default_price / market_price) so that total spending stays within the
# pop's budget regardless of price fluctuations.
#
# Requires: sul_demand_power variable map on locations
#
# =============================================================================

# pop_demand is a hardcoded key — engine reads it directly and also sources
# a per-pop scriptvalue. Each entry's final multiply pulls the location's
# sul_demand_<tier> script_value to apply GDP-based scaling, then divides
# by the price ratio to convert from budget share to affordable quantity.
