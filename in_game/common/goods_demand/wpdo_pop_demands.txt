# =============================================================================
# POP DEMANDS WITH GDP PER CAPITA SCALING
# =============================================================================
#
# This file REPLACEs vanilla pop_demands.txt to add GDP-based demand scaling.
# Each goods entry uses a category-specific GDP scale with elasticity dampening:
# Elasticity (demand growth rate past affordability threshold):
#   necessity = 0.25 (slow growth — always needed)
#   common    = 0.75 (moderate growth)
#   upper     = 1.0  (standard growth)
#   luxury    = 1.5  (fast growth — wealth-driven)
#   exotic    = 2.0  (fastest growth — pure luxury)
#
# Demand gate: max(0, (demand_power - price) / price) × elasticity
# Requires: wpdo_demand_power variable map on locations
#
# =============================================================================

##############################################################
# This is a special demands, as it has a hardcoded tag
