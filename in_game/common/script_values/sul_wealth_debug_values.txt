# Display-only script values for the wealth tooltip and debug panel.
# Tooltip values (deltas, totals, fill) read from cached variable maps
# populated by sul_wealth_write_maps. This avoids nested script_value
# resolution which the GUI engine may truncate at depth, and guarantees
# display matches computation.
# Debug values (fractions, targets, gold) compute live for the debug
# panel — acceptable there since it's a developer tool, not player-facing.
